# safe — static frontend

Публичный адрес `https://safe.rival-afk.com` обслуживает статическую страницу из `web/`.
Динамического backend, проксирования, журналов и переписывания URL в этом проекте больше нет.

## Запуск

Любой HTTP-сервер со статическим каталогом `web/`. На redmi сервис `safe` в runit
запускает встроенный Python HTTP-сервер на `127.0.0.1:8001`.

Публикация идёт через reverse tunnel:

```sh
VPS:18003 -> redmi:8001
```

 rival-auth проксирует `safe.rival-afk.com` на VPS `127.0.0.1:18003`.
